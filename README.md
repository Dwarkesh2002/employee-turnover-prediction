# Employee Turnover Prediction Using Machine Learning

## Overview

This project predicts whether an employee is likely to leave the company using Machine Learning techniques.
The system analyzes employee-related factors such as satisfaction level, salary, promotion history, work accidents, and department details to predict employee turnover.

The project helps organizations:

* Identify employees at risk of leaving
* Improve employee retention
* Support HR decision-making

# Machine Learning Process

## Step 1: Import Dataset

The HR dataset is loaded using Pandas.

## Step 2: Data Cleaning

Unnecessary and duplicate data are removed.

## Step 3: Feature Engineering

Categorical variables are converted into numerical format.

## Step 4: Train-Test Split

The dataset is divided into:

* Training Data
* Testing Data

## Step 5: Model Training

Machine Learning algorithms are trained on employee data.

## Step 6: Prediction

The model predicts whether an employee will:
